# Lume Blog RESTful API 接口规范

本接口服务为《Web前端框架程序设计》实验五专属服务端，由 **Node.js (v24)**、**Express** 与 **MySQL 8.0** 驱动。

### 统一设计规范
1. **统一返回格式**：全站接口返回统一 JSON 结构 `{ code, message, data }`。
2. **规范状态码**：遵循 RESTful 语义，使用 `200`、`201`、`400`、`401`、`404` 与 `500`。
3. **安全防注入**：所有 SQL 查询均使用 `mysql2/promise` 连接池与 `?` 参数化预编译占位符。
4. **CORS 跨域支持**：全站开启 CORS 允许前端 Vite 开发服务器跨域调用。
