# 🌟 Lume Blog（个人博客项目）

本项目为本学期 Vue.js 课程的综合设计大作业成果，最终目标是实现一个全功能的个人博客网站。本项目所有关于个人博客的代码均集中在本目录（`Lume Bolg`）下。

---

## 📌 实验一阶段成果：个人信息主页与 Vue 基础应用

本阶段严格遵照 **《实验一指导书》** 的各项要求进行开发：

### ✅ 1. 基本要求（必做项）完成情况
- [x] **单页 HTML + CDN 架构**：无需复杂打包，双击 `index.html` 即可在任意浏览器直接运行。
- [x] **选项式 API（Options API）**：完整运用 `data`、`methods`、`computed`、`watch` 和 `mounted` 五大选项。
- [x] **数据驱动展示**：所有姓名、学号、专业、简介及技能数据均由 `data()` 集中管理，无模板硬编码。
- [x] **核心指令全覆盖**：
  - `{{ }}` 插值表达式展示姓名、简介、统计数值；
  - `v-bind`（`:`）绑定头像 `src`、社交链接 `href`、动态 `class`；
  - `v-for` 与 `:key` 列表渲染技能卡片与标签数组；
  - `v-if / v-else` 与 `v-show` 控制详情与搜索空状态；
  - `v-on`（`@`）绑定事件监听；
  - `v-model` 双向数据绑定搜索输入框与编辑表单。
- [x] **技能筛选功能**：使用 `computed` 计算属性 `filteredSkills` 实时过滤。
- [x] **状态监听与生命周期**：使用 `watch` 监听搜索词变化并输出提示；在 `mounted` 输出初始化加载日志。

### 🚀 2. 拓展要求（选做项 · 冲刺满分 90~100 分）
- [x] **亮色 / 暗色主题切换**：支持一键切换夜间暗色（Dark Mode）与日间浅色模式，过渡动画平滑优雅。
- [x] **个人信息动态编辑**：支持点击“编辑资料”唤出弹窗，实时修改姓名、角色头衔、专业和简介，保存后页面立即响应式更新。

---

## 🖥️ 运行说明
在文件管理器中直接 **双击 `index.html`** 文件，即可在浏览器（Chrome、Edge 等）中运行与体验！
